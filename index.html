Flujo de Automatización

Arquitectura del pipeline configurado en GitHub Actions

01

Desarrollo Local & Commit

El desarrollador realiza modificaciones en los archivos HTML/CSS/JS y ejecuta git commit y git push.

02

GitHub Actions Runner

GitHub detecta el evento push en la rama main e inicializa un entorno de ejecución en Ubuntu con Node.js y las dependencias necesarias.

03

Inyección de Secrets

Se inyectan de forma cifrada las variables SURGE_LOGIN y SURGE_TOKEN sin exponer credenciales en el código fuente.

04

Publicación en Surge.sh

Surge sincroniza los archivos estáticos en su red global de distribución y actualiza el dominio en tiempo real con certificado HTTPS.

.github/workflows/main.yml
YAML
name: Deploy to Surge

on:
  push:
    branches:
      - main

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Deploy to Surge
        uses: dswistowski/surge-sh-action@v1
        with:
          domain: 'isak-practica-surge.surge.sh'
          project: '.'
          login: ${{ secrets.SURGE_LOGIN }}
          token: ${{ secrets.SURGE_TOKEN }}
